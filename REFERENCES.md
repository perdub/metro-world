# Architectural references

- [Hidden London — London Transport Museum](https://www.ltmuseum.co.uk/hidden-london): disused platforms, shelters and service corridors. Reference for brick and dim maintenance routes.
- [Art in the subway — Visit Stockholm](https://www.visitstockholm.com/see-do/attractions/art-in-the-subway/): distinctive station surfaces and colour treatment. Reference for rock and clean-colour variants.

These are visual references. No downloaded schematics, textures or copyrighted game assets are bundled; all structures are generated using Minecraft blocks.
