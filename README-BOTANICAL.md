# Ботанические боковые залы

`BotanicalAnnex.spec(stationSalt)` детерминированно выбирает один из четырёх залов. Планирование и построение используют один Spec: центр относительно станции `(72, -52)`, пол на уровне станции +2, локальные размеры X ±10, Z ±12, Y −3…12.

| Зал | Содержимое |
| --- | --- |
| Теплица | Остеклённый потолок с лампами, орошаемые грядки пшеницы и моркови, компостеры |
| Семенное хранилище | Три яруса полок, бочки с зелёными перегородками |
| Лаборатория | Кварцевые столы, стеклянные образцы, варочные стойки, котёл |
| Заросший питомник | Папоротники, азалии, листья и дерево среди бывших рабочих зон |

`BotanicalStructures.sample(x,y,z,spec)` возвращает блок или null за пределами зала. Внешние слои — камень, обсидиан и бедрок. Южный вход: X ±2, Z +12, три свободных блока над полом; этот же проход идёт до Z −7. Содержимое залов не перекрывает проход.

Во всех вариантах сундук находится в `(6, 1, -7)` относительно центра зала. Два блока над ним свободны; заполнение лута выполняет общий генератор. Входной коридор строится отдельно от зала и должен открыть портал во всех трёх слоях оболочки.

Чистые тесты проверяют воспроизводимость, охват вариантов, габариты, оболочку и непрерывность прохода. Проверка настоящих блоков, освещения и серверного запуска остаётся контейнерному CI.
